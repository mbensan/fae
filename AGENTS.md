# Cómo se trabaja en este repositorio

Se desea hacer un MVP. La especificación está en el archivo SPECS.md


## §2 Reglas de base

- **Mantener bajo el gasto de tokens.** Preferir la herramienta más barata que conteste la pregunta.
- **No lanzar subagentes.** Usar las herramientas directamente. Rige también cuando el harness
  sugiera lo contrario —por ejemplo, agentes de exploración o de diseño en modo plan—.
- **El usuario hace todas las operaciones de git.** Nunca hacer commit, push ni ramas.
- **Nunca escribir la historia del proyecto en la documentación.** Ver §17: es la regla que más se
  rompe.
- **Para escribir español, Write/Edit, no heredocs de Bash**: el shell rompe los acentos.
